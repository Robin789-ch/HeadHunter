# HeadHunter — Agentic Application

HeadHunter is a local-first agentic application. Its goal is to build an accurate professional profile, discover relevant opportunities, and prepare tailored applications while keeping the user in control.

## Planned features

- Guided professional profiling
- Daily, explained job recommendations
- Local Kanban board for reviewing opportunities
- Tailored CVs and cover letters generated with Typst
- Application and follow-up tracking

## Status

This project is currently in the research and design phase. The repository mainly contains specifications and architectural decisions; a working application has not been implemented yet.

## Principles

- Privacy-first and local-first
- No invented or unconfirmed qualifications
- Human approval before preparing or sending applications
